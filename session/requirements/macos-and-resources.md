# macOS 适配与资源优化

## 授权

2026-10-08，用户要求“解决一下mac的适配”，追加“不降低画质和流程性的前提下，同时也优化一下包体大小和运行内存占用”，并确认 Apple 芯片与 Intel 都需要。沿用现有设计、动作流程及本项目 Git 提交推送授权。

## 当前交付

新增 macOS 桌面宿主与两种架构发布脚本；共用原行为、几何与绘图；原始资产未修改。全量 15,349 帧经无损压缩和逐像素回查，发布素材减少 46.6%。缓存由全量预载改为 96 MiB 的滚动预读与 LRU，弱引用边界表避免旧帧滞留。

758 项共享检查、13 项 Windows 窗口检查和两端编译通过。独立存档的 Windows 预览完成；WPF 全帧实际解码一致性与 macOS 原生 CI 待补记，不能冒充全部平台验收。用户正式 Windows 安装、个人存档、自启和行为参数未改动。详见 `docs/macos-and-resources.md`。
