# 生成行为分类与提示词总表

以下为制作清单，不代表视频或首尾图已经全部生成。本轮只交付基础右行 W-R→W-R 的首尾图。其余先按顺序做端点，再生成视频；锚点字母见 [流程说明](README.md)。照片中的端坐低头、抬头注视、侧躺露肚、C形埋脸蜷睡、歪头和伸身抬爪继续约束动作，不把静态照片推断成某种固定性格或频率。

## 每条提示词的组合方法

复制“统一前缀”＋表中“动作提示词”＋对应的“循环／过渡结尾”。这些是可复制的运动描述；不要把表格标题、程序动作ID和锚点代号当成画面文字提交给视频模型。平台若有角色参考功能，放同一张B标准图；首尾槽放单猫端点图，不能把多视图标准板当成首帧。

**统一前缀：**

> 固定机位、固定构图的一镜到底2D绘本厚涂动画。输入图中的同一只成年蓝灰短毛猫，保持圆颊、金眼、短深色鼻口、自然灰色嘴垫、轻嘴线、粗尾和同一头身比例，保持笔触和颜色稳定。全身完整可见，位置、尺度、光线和浅灰背景固定。四肢连接与近远遮挡清楚，动作轻松自然。只有这一只猫，画面简洁，信息完全由身体动作表达。

**循环结尾：**

> 动作平稳重复，结束时精确回到尾帧的同一姿态、同一大小、同一位置和运动相位，与开头自然连续；首尾不添加停顿。头、脚、尾巴和毛纹在循环接缝连续。

**过渡结尾：**

> 从首帧姿态自然过渡到尾帧姿态，每个关节连续移动，重心和四肢承重合理。结束时准确落到尾帧，保持约0.3秒安定姿态，不能突然切图、变形或换脸。

请求、带路等视频只表现动作；触发频率、等待5分钟、鼠标距离、随机概率和2～60分钟停留仍由行为树决定，不交给视频模型表演。视频内不烘焙真实鼠标、逗猫棒、碗、猫窝或猫砂盆；接触锚点在制作对应端点时标定。

## 1. 待机与观察

| 素材ID／对应表现 | 首尾／类型 | 动作提示词 |
| --- | --- | --- |
| idle-blink／发呆眨眼 | I→I 循环 | 猫安静端坐，眼睛缓慢完整闭合一次，再自然睁开；身体只作极轻微呼吸，脚掌、头部尺度和尾根稳定。 |
| idle-look／看主人 | I→I 循环 | 保持端坐，视线轻轻抬向画面上方，再回到平视；头只小幅抬起和复位，耳朵微转，胸胯不移动。 |
| idle-ear-tail／耳尾微动 | I→I 循环 | 身体和脸安静不动，一只耳朵轻转后复位，尾尖轻轻弯动一次再归位；动作低频而克制。 |

## 2. 移动与坐站过渡

| 素材ID／对应表现 | 首尾／类型 | 动作提示词 |
| --- | --- | --- |
| walk-right／基础移动 | W-R→W-R 循环 | 面朝右方原地平稳走路，四足依次抬脚、前摆、落地承重，支撑脚相对身体后移，离地脚前摆；头安定、身体中心固定，尾巴轻微平衡。首轮完整可复制版见 walk-v1。 |
| stand-to-walk／起步 | S-R→W-R 过渡 | 从四脚落地的站姿轻微前移重心，一只后脚开始推进，前脚依次迈出，平顺进入尾图的步态相位；身体仍留在固定画布中心。 |
| walk-to-stand／停步 | W-R→S-R 过渡 | 从当前步态完成最后一次短步，抬起的脚依次落地，四脚收回中性站位，重心平稳停止；不能把悬空爪直接消失。 |
| stand-to-sit／坐下 | S-R→I-R 过渡 | 前脚支撑，后腿膝与跗关节自然弯曲，臀部向后下方坐实，胸部逐渐直立，尾巴绕到身旁；头部若需转向，分布在整个过渡中缓慢完成。 |
| sit-to-idle／坐稳发呆 | I-R→I-R 过渡 | 在端坐姿态中微微安定肩部重量，头自然抬到中性视线，眼睛放松地睁开，前爪和臀部接地点不变，结束安静发呆。 |
| sit-to-stand／起身 | I-R→S-R 过渡 | 猫向前移重心，后脚踏稳，后腿逐渐伸展抬起臀部，胸背回到自然站姿；前脚依次调整小步，头部连续转到朝右中性角度。 |

运行时 `move-to-sit` 可由“停步＋坐下”剪接制作；相接处共用 S-R 文件。左右移动先做右行验证，再评估逐帧镜像，绝不倒放视频。

## 3. 睡眠

| 素材ID／对应表现 | 首尾／类型 | 动作提示词 |
| --- | --- | --- |
| sit-to-sleep／入睡 | I→C 过渡 | 猫俯下胸部，前肘弯曲，后腿收向腹侧，身体侧向盘成自然C形，头轻轻收进前爪旁，粗尾环绕外侧，再合眼安定；各步骤连续，头与臀部不能瞬间对换方向。 |
| sleep-breathe／通用睡觉 | C→C 循环 | 猫保持紧凑C形蜷睡，头枕前爪、尾包身体；只有胸腹极轻微的浅呼吸，鼻尖枕点、脚、尾根和臀部位置稳定，整团体积基本不变。 |
| sleep-to-sit／醒来 | C→I 过渡 | 猫先睁眼抬头，尾巴轻轻松开，前爪撑起胸部，后躯保持承重，逐渐恢复端坐并看向主人；保持真实关节运动，不能把入睡视频简单倒放。 |

地面和猫窝共用同一睡猫资产，窝沿由程序遮挡。点击／拖拽即时打断由程序处理，不为了播完醒来动作阻塞用户操作。

## 4. 吃饭、喝水和猫砂

| 素材ID／对应表现 | 首尾／类型 | 动作提示词 |
| --- | --- | --- |
| eat-enter | S→E 过渡 | 四脚站稳，猫嗅一嗅前下方，再弯颈把嘴自然放到已约定的饭盆接触高度；盆由程序单独显示，画面仅保留猫。 |
| eat-loop | E→E 循环 | 保持低头取食姿态，细小而自然地取食、咀嚼和吞咽，头部只有小幅连贯运动；嘴垫形状不膨大，脚掌固定，保持同一嘴部接触点。 |
| eat-exit | E→S 过渡 | 猫咽下食物，轻舔一次嘴边，慢慢抬头恢复四脚站稳的中性姿态，颈部和嘴部自然复位。 |
| drink-enter | S→D 过渡 | 猫前脚踏稳，平缓低头，鼻尖靠近已约定的水面位置，背线和肩部保持稳定。 |
| drink-loop | D→D 循环 | 猫以细小、规律的舌头动作轻轻舔水，头部稳定，舌尖只在嘴前短暂出现；嘴部、下颌和前爪保持自然连接，水盆单独渲染。 |
| drink-exit | D→S 过渡 | 猫停止舔水，收回舌头，轻抿嘴后自然抬头，回到四脚站稳的姿态。 |
| toilet-enter | S→L 过渡 | 猫原地调整两步，背对或侧背对镜头，后腿自然蹲下，前脚撑稳，尾巴稍抬；身体保持成年猫的真实比例。 |
| toilet-hold | L→L 循环 | 猫安静保持低蹲姿，只有轻微呼吸和耳部微动，支撑稳定；不展示排泄物或额外特效。 |
| bury／埋砂 | L→S 过渡 | 猫恢复站姿，转向预定猫砂接触点，用前爪交替作两三次自然扒砂动作，后脚稳固，随后收爪站稳；猫砂由独立物件动画表达。 |

吃／喝／如厕结算仍由行为事件触发，不按视频时长自动扣盆，也不因为重播或打断重复结算。粮、水和砂盆的余量视觉属于另一层，不能跟猫一起生成。

## 5. 点击、悬停与亲昵

| 素材ID／对应表现 | 首尾／类型 | 动作提示词 |
| --- | --- | --- |
| pet-enjoy／点击回应 | I→I 一次性 | 猫略抬下巴，舒服地眯眼，轻轻偏头接受抚摸，再回到原端坐姿态；画面不出现人的手。 |
| paw-response／抬爪 | I→I 一次性 | 猫抬起一只前爪向主人方向轻轻伸出，肘腕自然弯曲，另一只前爪和后躯保持承重，再轻放原位。 |
| roll-belly／侧躺露肚 | I→I 一次性 | 猫自然侧躺，前爪放松弯曲，短暂露出圆肚子，一条后腿轻伸，随后撑起回到端坐；保留照片中放松而不僵直的姿态。此复杂动作后续宜拆 I→侧躺→I 两段。 |
| rub-cursor／蹭鼠标 | S→S 一次性 | 猫朝固定的接触位置轻轻伸头，用脸颊和额头蹭过该位置，再收头站稳；胡须和鼻口不变形，画面不生成鼠标指针或手。 |

点击池和待机池各保留12槽，非上限；上表仅基础项。其余拓展使用同一锚点合同：歪头、顶头、双爪抱、伸懒腰、轻拍、尾绕身、靠近贴贴、舔爪回应；待机拓展舔爪、洗脸、整理胸毛／侧毛、哈欠。每个变体一条视频，返同一个 I 或 S，先有素材才启用，不能把清单当作已经完成。

## 6. 拎起与落地

| 素材ID／对应表现 | 首尾／类型 | 动作提示词 |
| --- | --- | --- |
| drag-hold／被拎起 | H→H 循环 | 猫保持被托起的放松悬空姿态，身体重量自然下垂，四肢略弯，尾巴小幅摆动；头颈不过度拉长，体积不改变，没有手或吊绳。 |
| land／放下 | H→S 过渡 | 猫接近地面时依次伸出脚掌，前后脚柔和落地，腿部自然缓冲，再站稳；身体不压扁、不弹飞。 |

实际抬升／鼠标跟随仍由程序处理。放进猫窝后接入对应的坐下／入睡，不直接把悬空猫切成睡猫。拖拽开始不可等待动画结束。

## 7. 逗猫棒

| 素材ID／对应表现 | 首尾／类型 | 动作提示词 |
| --- | --- | --- |
| toy-chase／外圈追跑 | 跑步相位→同相位 循环 | 猫朝右原地轻快追跑，四足接地和离地顺序符合猫的自然跑姿，视线追踪前方固定目标点，身体中心留在画布内；不出现羽毛或棒。跑姿另立锚点，不把慢走加速当成跑。 |
| toy-ready／近身低伏 | S→P 过渡 | 猫到达目标前微屈前腿、降低胸部，后脚稳固，眼睛专注看向前上方约定目标点，尾尖轻动。 |
| toy-bat／内圈抓棒 | P→P 循环 | 猫以一只或交替两只前爪向近身固定目标点作短促抓拍，另一只脚或后躯稳定承重，爪子收回预备姿态；身体不平移，目标物不烘焙进画面。 |
| toy-settle | P→S 过渡 | 猫停止抓拍，前爪轻放，抬起胸部，尾巴安静下来，回到自然站姿。 |

双圈判断不画光圈；目标移远立即恢复追跑，内圈贴近抓拍，无固定观察等待循环。视频不能强加一段不可打断的长扑。

## 8. 请求与带路

| 素材ID／对应表现 | 首尾／类型 | 动作提示词 |
| --- | --- | --- |
| request-food | I→I 循环 | 猫温和地抬头望主人，再看向约定饭盆方向，轻轻抬一只前爪又放下，回头等待；神态期待，不表现衰弱或痛苦。 |
| request-water | I→I 循环 | 猫先望向约定水盆方向，轻舔一下嘴边，再抬头看主人，安静等待后回到原坐姿。 |
| request-litter | I→I 循环 | 猫回头看向约定猫砂盆方向，前爪作一次轻微扒地示意，再转头看主人，回到等待姿态。 |
| guide-look | S→S 一次性 | 猫停下脚步，小幅转头回望主人方向，耳朵转向身后，短暂停留后重新朝前；身体与脚的位置保持稳定，头部逐渐转动。 |
| guide-food | S→S 一次性 | 猫站在约定饭盆旁，低头嗅向盆口位置，再抬头看主人，轻举前爪示意后放下。 |
| guide-water | S→S 一次性 | 猫站在约定水盆旁，把鼻尖靠向水面接触点，再抬头看主人，轻舔嘴边后回到站姿。 |
| guide-litter | S→S 一次性 | 猫站在约定砂盆旁，朝盆内方向作一次小幅扒砂示意，再抬头看主人，收爪站稳。 |
| care-thanks | I→I 一次性 | 猫安静望着主人，缓慢眯眼并轻轻点头，尾尖放松地弯动一下，再回到端坐；不用爱心或文字。 |

`request-walk`、`guide-walk` 使用基础移动表现，路径、停顿、回头和终点由程序控制。请求发生在空盆／满砂持续5分钟之后；鼠标到猫身立即切换带路，不能等整段请求视频播完。只有催促，没有不可逆惩罚。

## 制作顺序

先过基础 W-R 锚点和一条步行循环；确认角色未漂移、腿没有互换后，再制作中性站姿 S、坐姿 I 及其过渡；之后制作 C 睡眠和入睡／醒来；最后照料、请求带路、逗猫、点击扩展。节日围脖和生日皮肤留后续，在每套皮肤内复用统一锚点，不能混搭不同服饰的首尾图。
