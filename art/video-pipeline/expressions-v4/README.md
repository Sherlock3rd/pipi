## 制作顺序与时长

先做58、60、67—70、62、71—74、64、75—78，验证躺下与三档点击；接着做83—85掩面睡眠；然后52—57左右扶墙；最后哈欠、叫声及伸懒腰。59、61、63、65是必要的返回连接，不能漏做。

逐条目标时长1.2—5.6秒，不固定5秒。轻抖1.2秒、较强抖动加回头叫2.2秒；平躺起身2.6秒，仰躺需先翻身，给3秒；哈欠3.4秒；站姿伸展4秒；睡眠循环5.6秒。时长是动作设计目标，返片按真实有效动作时长验收，不能强行压速对表。

走路叫特别保留旧步速：右行现有循环39帧/24fps=1.625秒，目标两个周期3.25秒；左行现有完整循环120帧/24fps=5秒。模型若不能直接使用小数秒，选更长档，返片保留完整周期；不把右步态放慢到5秒，也不把左步态压到2秒。原有动作仍保持原速。

## 输入与验收

统一1672×941画幅、固定机位和浅暖灰背景，背景并非透明。动画只画猫，墙、地面线、道具、窗口阴影、字幕及人手都不进入视频。新图由内置image_gen制作，生成提示与来源记录见[关键图生成记录](关键图生成记录.json)。最终配图沿用相同角色，不替换运行时原图。

所有同锚点首尾图按SHA256验证完全相同；循环首尾相同不代表中间静止，单次动作A→A也不代表循环播放。先检查鼻口/眼脸/成年体态、四肢与尾巴，再检查进入/退出支撑、全片每相邻帧宽高突变、步态速度和循环相位。首尾静态通过不代表中间动画通过。

**源图不同姿态的支撑位置不能用整图最低像素一刀切。** 平躺用侧腹/背部接触，站立用承重脚，扶墙用后脚＋前掌接触线。已有F/SR等的源图基准也略有差异；返片必须按真实支撑位置连续标注、做统一世界地面校准，禁止缩放猫体补高度，禁止逐帧紧框裁剪。新锚点当前是可用的视频输入候选，未声称已完成运行时逐像素对齐。

原始视频按编号返还，附工具/模型、实际时长和帧率（若能获取）。不要提前加速、倒放、镜像、补帧、剪掉关键接触动作。声音后期单独接入：叫声图只控制一次口型，无文本台词，继续遵守静音与全屏不打扰。

重建与检查：`python tools/package_expressions_v4.py`（需Pillow），生成动作表/配图目录/HTML并验证94张端点拷贝、12图尺寸及进入退出路径；结果见校验结果.json。原有检查工具继续用于返片后的动态验证。
