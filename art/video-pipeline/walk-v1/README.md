首尾使用同一张右行步态相位图 W-R，固定大小、鼻口、四肢、脚底和镜头。一个循环回到相同姿态，**中间应真实完成迈步，不能只晃尾巴或整张平移**。这里不做“站住→走→站住”，后者以后拆成起步、循环、停步三段。

输入为1672×941近16:9原始PNG，保持文件完整上传，不拉伸为别的比例。若工具必须精确16:9，使用其保持比例的适配／留边，不裁猫。建议首轮5秒、原生帧率、1080p（如支持），约4个平稳步态周期；周期数是运动目标，成片仍需审查。优先选择可同时上传首尾帧的模式；如果平台仅接受一张图，先上传 start.png，但末尾姿态只能由提示词引导，锁尾不成立。

循环的最后一帧不额外停顿。后续拆出一个完整周期时通常使用起点、排除重复终点；检查接缝速度和脚的支撑相位，不直接用两张相同图掩盖中间错误。视频原片回传后再决定具体30张取样与播放时长。

本图由内置 image_gen 基于已保存的 `walk-key-a` 和照片身份／B角色标准制作，四肢静态可解释，鼻口保持灰色短口鼻。其毛发刻画仍较细，属于**本次待评审锚点**，并非用户最终认可。首尾不能分开重新生成，否则会再次引入差异。追溯见 [anchor-prompt.md](anchor-prompt.md) 和 `anchor.json`。
