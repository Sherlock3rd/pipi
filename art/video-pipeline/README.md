## 一致性合同

1. 固定 B 画风：成年蓝灰短毛猫、圆颊、金黄色眼、紧凑深鼻、自然灰色嘴垫、轻嘴线、粗尾；不用幼猫比例、白嘴套或夸张笑嘴。照片只约束身份／解剖，不让视频模型把画风变为照片。
2. 固定画幅、机位、光线、背景、角色占画比例和接地点。每次上传端点原文件，不截图、不二次美颜、不裁出不同构图。
3. 一个片段只做一个动作。镜头锁定，无推拉、摇移、环绕、景深变化。猫的桌面位移由程序完成，视频内原地走；耳朵／尾巴可有克制的自然动作。
4. 猫窝、饭盆、水盆、猫砂盆、逗猫棒独立渲染和拖动，不烘焙到角色视频。吃喝片段约定嘴部接触点；涉及物品交互的后续样本另做定位图，先定接触高度再生成。
5. 不出现台词、字幕、气泡、浮动符号、光圈、需求条或照料数字。请求靠看向物品、回头、抬爪等动作表达；不会把“饿了”变成惩罚或生病。
6. 同一动作左右方向先检验镜像是否保留身份与光线；不能把视频倒放当成走路另一方向。睡醒、起身等动作也独立生成，不能默认倒放入睡就自然。

## 外部生成与返片

首轮推荐短片，优先首尾帧控制；生成工具和版本由用户指定。分辨率先1080p（如可选），原始帧率不强行改变；模型若只支持固定帧率／时长，以其可用选项为准。先关掉运镜、配乐、自动配音与额外风格增强。只有首帧输入的模式只能作为探索，不能把提示词写了“同图结束”当成真正锁尾。

请保留原始 MP4/MOV、工具／模型名称、提示词、生成参数及种子（若有），别先做加速、剪辑、补帧或滤镜。回来后先检查整段原视频，再挑一段完整步态周期；不因视频更顺就略过逐帧肢体审核。

后续拆帧：读取源帧率／时间戳→挑完整动作或完整循环→固定整段裁切与尺度→前景分割与边缘处理→脚底锚点／嘴部接触点统一→透明PNG→检查深浅背景与实际尺寸→接入预览→运行时验证。保留原视频和抽帧时间表，避免逐帧紧框裁剪引入漂移。

目标仍为每基础动作30帧，但30帧不等于30fps。例如30张图按24fps播放是1.25秒。不能把5秒视频直接压成1秒；先选一个干净周期，再按原动作时长设置帧率。若选中周期少于30张原生独立画面，不复制／倒放凑数；回到生成端调整节奏或原生帧率，再审查。补帧若以后需要，必须单独审查爪与遮挡，不能掩盖断腿。

当前背景为浅暖灰，端点有极轻微数值变化；去背景采用前景分割／精修，不用单一颜色阈值粗暴抠灰猫，不把灰毛、金眼或胡须误删。视频的背景不视为真实透明通道。
