# 陈皮基础动作视频包 v2

本版替代v1作为制作清单：增加正面待机与完整左右方向连接。右行视频已经认可，不必重做；其他视频等待生成和验收。

## 用法

每个编号文件夹分别上传 `首帧.png` 和 `尾帧.png`，复制 `提示词.txt` 全文；`关键词.txt` 是动作速查。每条先用5秒，沿用成功右移动视频的模型和设置，保持原图比例，不单独裁切端点。

陈皮有轻微大小眼：自身左眼稍小；正面对镜头时是画面右侧眼睛稍小。只保留一点自然差异，不能夸张成眯眼、困倦或病眼。转头、转身与眨眼后恢复时，始终是自身左眼稍小，不能按画面左右重新分配，也不能因自动对称美化而抹掉。侧面受透视影响只见一眼时，不为展示大小眼强行扭正脸；闭眼睡姿不强行画出眼球。

所有方向都是画面方向。左右转身必须真实迈步；不能镜像整个视频，否则会调换大小眼身份。提示词中的度数、周期数是生成目标，仍以返片审查为准。

## 完整连接

正面坐姿 F ↔ 朝右站姿 SR ↔ 右行 WR

正面坐姿 F ↔ 朝左站姿 SL ↔ 左行 WL

朝右站姿 SR ↔ 朝左站姿 SL（经过正面站立，不能坐下）

正面坐姿 F ↔ 侧坐 I ↔ 蜷睡 C

右行转左行：11停步 → 15转身 → 12起步 → 14左行循环。左行转右行：13停步 → 16转身 → 10起步 → 已有右行循环。每段交接共用同一原图。起步尾部短定格由拆帧时裁掉，循环不保留停顿。
