# 落地、入睡与睡眠循环的支撑脚对齐（2026-09-19）

用户先指出下落到待机有一次下跳，随后指出睡眠循环轻微上下跳、待机进睡眠高度线乱变，明确重点是脚底没有统一位置。本轮合并检查34→01→17→19→20及20循环，同时回归21→18→01醒来路径。

两个原因：34落地末帧仍使用旧画布锚点，01已使用接触锚点，共同坐姿在切换时向下移2.797逻辑单位；此前全图最低像素的校准把摆动尾巴当成支撑脚，17/19等片段的整猫高度因此跟着尾巴变化。20呼吸轮廓的阈值变化还会带来0.5625单位的整体高度跳动。

34增加landingContactY，仅末尾20%平滑接到01支撑线，空中下落前段保持原轨迹。01/17/18跟踪经画面核对的前脚区域；19/21在前脚与蜷卧身体接触面之间转移支撑。排除原片脚边浅色残留，平滑像素阈值噪声，并让相邻片段端点共用坐姿/侧坐/蜷卧三个支撑基准。20全循环使用固定锚点，保留原呼吸姿态而不拿轮廓逐帧升降整只猫。PNG/视频、猫体大小、帧数和播放时长均不变；埋屎抬手的既有倍率也未变。

工具tools/calibrate_ground_contacts.py可重建这些元数据。3463个既有groundContacts的帧数未变；落地使用独立末端标记，不能把悬空阶段也钉到地面。既有“全图最低点就是脚底”的说明由本次覆盖。

验证：316项检查通过，覆盖落地平滑收敛、显式land和从drag退出到idle/sleep、共享支撑端点、固定睡眠循环高度、原下落前段及原速度。133个独立共同特征接缝样本通过，含新增34→01、01→17、20首尾，以及121种呼吸阶段唤醒；最大比例差仍为0.265%，所有接缝平均特征位置变化小于1.5逻辑单位。数据见docs/qa/landing-sleep/，实机核验结果随后补充。

实机核验：15秒地面放下预览实际经历32→33→34→01，27秒原地入睡预览实际经历01→17→19→20并跨越3次睡眠循环回绕；世界Y全程固定，两组无错误日志。已在截图叠加固定地面参考线核对脚部与落地接缝，图像保留artifacts/landing-seam/；量化记录docs/qa/landing-sleep/native.json。Release构建零警告零错误，自包含发布完成。
