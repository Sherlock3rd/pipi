# 待机与互动的脚底高度（2026-09-19）

用户反馈待机到卖萌仍有一次高度不齐，并再次强调重点是脚部高度。本轮检查所有共用正面坐姿的互动入口与返回待机路径。

原因是此前只校准了基础/照料32段，互动37～42、45～47和51仍使用旧画布锚点0.921875，而待机01已使用实际前脚支撑467/512。即使根节点Y完全不动，切片也会产生约2.8逻辑单位的高度跳变。此前校准覆盖不足，并非用户观察误差。

37卖萌、38蹭手、39伸爪、45～47照料请求和51致谢均使用同一个固定坐姿脚底基准。40躺下、41翻滚和42坐起在支撑脚与身体下侧之间连续转移支撑，排除左侧尾巴与抬起的爪；进出端点共用坐姿/侧卧基准。新增1210个支撑采样，总计4673个。只改竖向接触锚点，原PNG、体型、帧数、帧率、时长与其他片段校准均不变。

验证：332项模型/播放检查通过；159个共同实体特征接缝通过，最大比例差0.265%，接缝平均特征位移均小于1.5逻辑单位。增加了互动入/出/循环首尾以及完整翻滚链验证。与上一版manifest逐字段比较，除10段接触数组和版本标记外完全一致。实机动态核验与安装结果随后记录。

悬停触发条件本轮未修改，仍沿用清醒空闲时连续5秒原地蹭手。预览夹具直接调用模型入口验证渲染高度，不作为桌面鼠标命中的端到端验证；用户关于鼠标未蹭手的触发问题尚未独立定位。


实机核验：36秒隔离预览连续经历01→37→01→39→01→40→41→42→01→38→01，125组PNG/元数据采样，根节点始终X410/Y453.25；固定地面线对照已目视检查坐姿支撑脚、翻滚身体接触及回坐接缝，无错误日志。平均帧间隔22.08ms，最大153.76ms；记录如实保留，不据此承诺输入延迟。5883帧/5道具引用检查通过，自包含Release发布成功。正式存档已备份before-interaction-contact，等待旧进程退出后更新运行包，DLL/manifest哈希一致。最终启动核验和Git总账随后补充。


最终启动核验：正式程序响应正常，诊断写入晚于启动时间，sceneVisibility=Visible、native.visible=true，无启动后新错误日志。安装DLL与发布文件、安装manifest与源文件分别SHA256一致，正式存档已备份且保留。
