# 吃喝低头加速（2026-09-20）

用户要求“把吃饭喝水中，脑袋朝下动作的速度加速50%”。本条为最新明确例外，覆盖之前只有埋砂抬手可变速的范围约束，仅新增吃饭/喝水的低头准备片段22。

在22的素材元数据设置 `eatDrinkPlaybackRate=1.5`，仅在 `eat` / `drink` 内应用：121帧按36 fps播放，约5.04秒缩短为3.36秒。23咀嚼、25舔水、24抬头仍24 fps，各约5.04秒。单次吃喝总时长约13.44秒。速度增加50%对应时长除以1.5，不是时长减半。

动作期限和摄入窗口使用相同场景速度。低头不扣库存，实际摄入循环开始后按原节奏分四次扣除一层，抬头不再扣。现有接近/转身/停步与中断逻辑不变；原帧数、体型、脚底、盆口位置和每帧配准均保留。29埋砂3倍速及其他动作的原速规则继续生效。

验证：379项自动检查通过；新增逐帧抽样覆盖22的全部121帧，验证36 fps下源帧、宽高、接触锚点均相同；检查22→23/25→24完整片段衔接、两种摄入窗口和库存、中断。更新旧的固定5秒准备测试为当前准备窗口断言。真实WPF预览、安装与Git交付结果记录于本次会话。
