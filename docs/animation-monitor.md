# 动画逐帧连续性监测

用户再次看到低头转吃喝时整体宽度跳变，并要求可重复的监测工具。之前的159项接缝检查只比较选定片段的末帧和首帧，未检查片段内部最后几帧；低头22和收头24都在116→117帧恢复了源画面横向比例，因此漏检。此前“端点通过”的结论不能代表整段连续。

本工具先由桌宠程序自身的WPF绘制函数导出透明逐帧图，复用裁切、锚点和校准处理，固定世界原点，按2像素/逻辑单位采样。Python工具逐帧检查每段内部、循环首尾和常用行为接缝，分别记录身体横向/纵向比例、位移、可见轮廓宽高与底边变化。吃喝四段使用已核对的躯干区域，排除低头、舌头和尾尖动作，避免将自然低头误判为整猫变矮。

报告包含JSON和离线HTML，列出异常帧号、前后图和叠图。稳定身体特征支持的比例突变返回退出码1；轮廓变化、低置信度匹配列为人工复核项，不能擅自视为通过。底边可能是尾巴，不等同于支撑脚。导出固定原点的单猫图用于检查素材与渲染；物件遮挡、真实移动、鼠标输入仍需场景预览。诊断叠图不会应用于桌宠播放。

安装Python依赖：`python -m pip install -r tools/requirements-animation-monitor.txt`。

完整检查（默认全部video片段及常用接缝）：

```powershell
./tools/check-animation.ps1 -Python '你的python.exe完整路径'
```

只检查吃喝（包括低头、两个循环和收头，共484帧）：

```powershell
./tools/check-animation.ps1 -Python '你的python.exe完整路径' -Clips '22,23,24,25'
```

可用`-Output`指定输出目录，`-OpenCvPath`指定已有OpenCV依赖目录。默认输出为`artifacts/animation-monitor/latest/report/index.html`。所有帧、网页和截图留在本地忽略目录，不包含存档；工具不会安装到正式桌宠、改照料状态或抢占正式实例。

也可直接调用自包含程序的`--audit-animations 输出目录 --audit-clips 22,23,24,25`，再运行`python tools/check_animation_continuity.py 输出目录 --out 报告目录`。省略`--audit-clips`导出所有video片段。`--self-test`验证原样帧被接受、人工注入的2%横向跳变被检出。
