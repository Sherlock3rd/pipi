# 有需求才请求，在对应物品处表现

2026-09-20 用户调整：吃喝请求不能仅由空盆触发，需当前确实要吃喝；食水请求在对应物品位置，猫砂清理请求在盆旁按摆放寻找空位。

需求判定复用现有 FoodClock/WaterClock.NextDue，不增加与随机照料冲突的饥渴阈值；保留库存为空5分钟条件。猫砂满5分钟规则不变。取消旧存档的未到期食水请求，但不重抽期限、补库存或清空缺货计时。

食水请求与示意共用实际吃喝目标（盆口左94逻辑单位的猫根节点）；猫砂以自身位置调用全部家具/屏幕边界的最近空位搜索，支持左右避让及无解时最大净空兜底。移动物品后每帧重新取得目标，使用原行走、转向和停步动画，不瞬移、不改变原动作时长。
