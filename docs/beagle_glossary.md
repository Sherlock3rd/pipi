# 桌面宠物术语表

保留源规范要求的 `beagle_glossary.md` 路径以便复用。Beagle、地块结构、社交类型、友军判定、事件广播是原项目示例，不作为本桌宠项目的设计事实。

## specrule

本会话中指已有 Rules Bootstrap Spec 及其“规则—会话—错题—复用”执行体系。入口：[基础规则](../rules/rules.md)。

## 桌面宠物

在系统桌面显示并与用户交互的角色。本项目首版为轻量 2D 小猫，自主移动、可喂饭喂水并拖回猫窝。

## 桌面宿主

负责窗口、透明、置顶、系统菜单与生命周期的程序层。当前原型采用 WPF / .NET 10 与 Win32 窗口接口。

## 动画状态

表示宠物当前行为的状态，例如待机、行走、被拖拽。仅是术语示例，不构成本项目已确认动画清单。

## 精灵图

将多帧角色图像排列为图集的资源形式。需与帧顺序、尺寸、锚点等元数据对应。

## 点击穿透

让指定透明区域的鼠标事件传给后面的应用；具体交互边界在实现时确定并验证。

## Skill

为 Agent 提供特定工作流说明及辅助资源的技能包。不能把 skill 可安装等同于产品成熟或桌宠框架已就绪。

## 行为树

用条件与动作节点组织角色决策的结构。当前原型使用 Selector、Sequence、Condition 和动作节点，动作执行器负责行走及吃喝等持续行为。不把任意随机动作直接称为行为树。

## 猫窝

首次默认位于桌面右下角，拖入有效区域高亮、释放后入窝睡觉；点击可立即唤醒，也能按作息／需求自然醒。猫窝显示首次运行至今的自然时间跨度，命中几何细节原型阶段验证，见[需求简述](../spec/desktop-cat-brief.md)。

## 系统有效运行时间

用户定义为电脑处于运行状态的时长，包括桌宠完全退出后的时间，排除睡眠／休眠。不是自然时间差，也不是桌宠进程存活时长；跨重启记录方案见[实施计划](../spec/desktop-cat-implementation-plan.md)。

## 日期时间与陪伴时长

日期时间用于作息与后续特殊日期皮肤。陪伴时长按首次运行至今的自然时间跨度显示，包含关机和桌宠退出时间，不与需求增长的有效运行时钟混用。

## 饥渴需求与盆库存

饥饿和口渴随系统有效运行时长增加，表示猫的照料需要；库存表示饭盆里的粮、水盆里的水，只随实际吃喝减少。补盆只加库存，吃喝才缓解需求；退出桌宠后补增需求，不补扣库存。

## 动画变体

同一个逻辑行为下可替换的不同视觉表现，如点击抚摸的眯眼或歪头。由素材配置选择，不创建新的照料事件，也不改变行为时序。预留槽位尚无成品素材，默认不参与播放；详见[资源说明](../assets/pets/bluecat/README.md)。

## 催促

缺粮、缺水或猫砂脏时请求主人处理的动作／声音表现，是未照料的唯一负面反馈；有冷却与静音控制，不附带惩罚。执行细则见[补充规范](../spec/desktop-cat-care-and-interaction.md)。

## 视觉过渡片段

连接两种姿态的一次性序列帧，如移动到坐下、坐下到睡觉。`SpritePlayback` 负责衔接与独立播放时钟，逻辑行为和照料仍即时更新；用户交互可打断，不需要等过渡播完。每段帧数与播放 FPS 分别配置。

## 视频首尾锚点

跨片段共用的固定角色端点图，约束外观、机位、大小、接地点和姿态。循环用A→A，过渡用A→B，下一段从同一B开始。图相同不保证运动相位／速度连续，仍需检查真实视频。见[视频制作规范](../art/video-pipeline/README.md)。


## 动作接触点与支撑面
动作接触点是嘴、脚等与物件实际接触的位置；它不一定等于角色根节点。支撑面是坐垫或猫砂表面的局部显示高度，世界坐标仍可保持底部水平线。见[对齐实现](interaction-alignment.md)。

## 同姿态端点比例校准
用共享姿态在不同片段端点的主体高度确定显示比例，再在片段内平缓插值。保留固定根节点，不把每帧外框压缩为同样大小。


## 共同实体特征配准
在同姿态片段间匹配毛发等实际对应特征，剔除不一致点后估计统一比例与位置。不用耳朵/尾巴变化影响的总外框高度判断体型。

## 呼吸阶段承接
在睡眠呼吸任一帧被唤醒时，令醒来首帧承接当时的身体比例与位置，再短时平缓回到原醒来片段，交互即时生效。

## 支撑面与落脚锚点
支撑面是猫当前落在的地面、坐垫或猫砂表面；落脚锚点是原帧中脚底或蜷卧身体的接触边。两者通过竖向平移对齐，不通过缩放猫体对齐。支撑身份随模型保留，进出时按水平位置连续变化。

## 埋砂覆盖进度

单个污物被砂覆盖的程度，随实际刨砂动作增加，支持中断和存档恢复。覆盖完成仍占一档脏污，只有清理才移除；画面用露出的深色部分与浅色砂堆表达，不显示数值。
