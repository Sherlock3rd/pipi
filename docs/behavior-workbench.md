# 行为工作台

入口：系统托盘 →「行为工作台 · 流程与参数」，或小猫设置窗口里的同名按钮。

## 怎么用

1. 在「全局流程」查看优先级；在「睡姿与反应」查看实际存在的姿态进入、循环、退出关系。可以缩放与滚动，点节点在右侧编辑。
2. 数字先作为草稿；权重旁实时显示同组占比。权重0只排除随机抽取，不删除必要的过渡动画。每组至少有一项大于0；关闭睡姿短动作可把“选择短动作的概率”设为0。
3. 点「保存并应用」写入独立行为配置并更新当前猫的后续决策，不重新启动、不重播或截断当前动作。
4. 吃饭、喝水、如厕范围默认从下一次排期使用。勾选「从现在重新计时」会重排当前三项期限；库存和缺货起点不变，不补扣粮水。当前尚未补给的吃喝请求可能因需求延后而结束。
5. 「撤销草稿」回到运行中的值；「默认草稿」载入原默认值但不自动应用。可导入/导出JSON方案；关闭未保存窗口时询问保存/放弃/取消。

右下角显示当前实际分支、最近分支变化和三项照料剩余时间。图中绿色为运行分支，描边为选中节点。面板内显示策划参数，不在猫身上新增台词、气泡或照料数字。

## 本轮可调范围

53项参数包括：安静入睡与休息周期、入睡保护、独立照料周期、空盆/满砂请求等待与轮换、跟随距离/回头步长、悬停/连击/长按、追逐/抓拨距离、地面五睡姿权重、侧躺换姿权重、四姿态各三类短动作权重、短动作/换姿概率与间隔、扶墙开关/概率/停留、长行程叫声频率、坐姿叫声冷却、起身伸展概率、夜间时间段和唤醒保护。

固定约束不作为概率：直接输入响应、物品/空位安全、已发生摄入、真实动画首尾连通和素材时长。全屏避让在宿主层执行，不是猫随机行为。现有动画缺片不能通过参数消除；侧坐直接站起、站立直接趴下仍见[缺片清单](expressions-v4-runtime.md)。本轮是参数编辑器，不支持自由拖接或删除行为逻辑。

## 生效与保存

- 个人配置：`%LOCALAPPDATA%\Chenpi\behavior-settings.json`，与宠物存档分开；临时文件原子替换并保留`.bak`。不提交个人配置。
- 启动先加载配置，再构造行为模型；桌面/悬浮宿主切换继续使用同一模型与工作台，不重复创建调度器。
- 参数变化重新安排下一次睡姿小动作及坐姿叫声冷却，已播放动作、点击窗口起点、入睡保护截止和既有休息周期继续保留。显式重排仅影响三项照料期限。
- 限制非有限数、未知键、版本错误、超范围、倒置时间范围、抓拨距离大于追逐距离、整组零权重。错误时不应用草稿；损坏文件从备份恢复或保留文件并使用默认值。
- 默认参数保持前一版的范围与权重，吃喝头部2.25倍速及所有动画几何不变。本轮不修改PNG或视频。
