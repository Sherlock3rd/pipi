# 支撑平面与猫窝尺寸复查（2026-09-19）

用户再次指出猫的平面高度与猫窝、猫砂盆不一致，猫窝明显偏小。此前只验证固定高度、动作终点和物件中心，未完整约束脚底接触，也让进入动作后才升高、前沿过早遮挡。

猫窝统一扩大1.6倍，196×146改为313.6×233.6逻辑单位，猫体大小保持不变。绘制、前沿、点击、放回窝内、边界、设置入口、休息避让一起更新。新布局为加宽的窝与猫砂盆留出位置；已有保存的横坐标只作必要屏幕边界约束，不重新排列用户家具。裁切后坐垫前部的接触线约在图高68%处，因此支撑高度为233.6×0.32=74.752；猫砂面仍为50，地面仍为工作区底线。

`SurfaceSupport` 随模型保存本次支撑物件身份，跨WPF宿主重建仍有效。有意走向猫窝/猫砂盆时，在到达前按位置平滑升高；到达后、换动作或被点击时不重算为地面，横向离开后降回地面。取消如厕26的按帧升高及跟随滤波滞后。进窝路径与睡眠共用同一横向显示根节点，消除到达时20单位跳位。路过未使用的物件仍沿地面行走。

进出期间猫先位于侧沿前方，身体进入坐垫范围才使用窝沿前景，避免半身被侧扶手切掉；猫砂盆完全上到砂面后使用弧形前沿。进入和离开仍复用现有走路素材，属于连续位置过渡，并未制作新的攀爬/跳跃动画。

32段落地动作共3463帧增加`groundContacts`：读取至少4个不透明像素的最低有效行，作为脚底或蜷卧身体的接触边。只调整竖向锚点，不改变图片、宽高或身体比例；保留现有共同特征比例/横向校准，落地动作的竖向接触优先于原位移校准。拎起、悬空和其他未纳入动作保留原始轨迹。查看器同步读取，呼吸中断唤醒后再次约束接触线。工具`tools/calibrate_ground_contacts.py`可重建数据。

验证：256项回归通过，覆盖到达前上升、到达与中断高度连续、离开解除支撑、普通路过不吸附、放大后的放回范围、进窝遮挡切换及3463个落地锚点。5883帧及5道具引用检查通过；更新接触锚点后的130个共同特征接缝检查通过，最大实体比例差仍0.265%，均值位置差小于1.5逻辑单位。原始PNG没有改写。

真实WPF连续采样检查了1倍显示的走进猫窝→入睡、窝内醒来→离开，以及0.8倍显示的走入猫砂盆→如厕→换位→埋砂→离开。进窝中途发现侧沿过早遮挡，修正后重新跑完整入窝路径。猫窝落定与睡醒支撑74.752、如厕/埋砂支撑50、普通地面为0；实际脚底锚点与这些平面对齐。截图与原始采样仅保留在忽略目录`artifacts/support-plane/`，量化结果见`docs/qa/support-plane/`。
