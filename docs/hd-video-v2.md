# 原片高清重提与轮廓白点修复

2026-09-18，按用户反馈模糊和偶发白点修复。保持陈皮现有288逻辑尺寸、底部水平线、动作时序、独立左右图与大小眼身份。

旧链路原视频→640×360→256画布→离线去白边→运行时再柔化。新链路从保留原视频读取颜色，在原分辨率根据主体遮罩估计透明覆盖并消除背景混色，预乘颜色与透明覆盖一起重采样至512画布。不是放大旧256帧或生成新角色。轮廓附近的近白污染取邻近实体毛色，保留内部眼睛高光。PNG量化后再次清除孤立透明分量，避免低透明连接断开后产生闪点。

`videoMattePrepared=true`使主程序和动作查看器跳过重复清理；高清帧不再强制解码为256。缓存裁去透明留白，并保留原画布归一化bounds用于绘制和点击，避免逐帧居中导致抖动。估算纯像素缓存432.2 MiB，PNG总计142.7 MiB；不等于实际进程总内存。

复现：保留源视频在art/video-pipeline/basic-v2/returned/00—21。若artifacts/basic-video-masks缺失，先运行tools/extract_basic_video_candidates.py；00使用同模块extract('00')生成缓存。运行tools/rebuild_hd_video.py生成全部HD帧及清单。tools/check_hd_video.py检查量化后的每一帧；tools/check_runtime_assets.py核对全部引用及透明边界。旧提帧工具会清除高清标记，不能把旧低清输出标记为已准备高清遮罩。

验证：168项模型/动作/边缘回归通过；2253帧尺寸及引用检查通过。每帧alpha>4的连通区域仅主体一个；轮廓内侧距离小于3像素、alpha>25且RGB各通道>220的污染像素为0。此阈值审计不等同所有肉眼可见闪烁完全消失，原视频内部纹理变化仍属于原片内容。

WPF实际渲染证据在artifacts/hd-qa，包含放大待机、左行查看器、左移动、睡眠与点击唤醒。唤醒前后世界锚点差为0；睡醒预览平均帧间隔16.83ms，左移动样本16.79ms。只代表本轮有限时长运行样本，未宣称人工观看全部2253帧。旧素材与原视频保留。
