# 物件与动作对齐修正

2026-09-18 用户反馈猫砂盆过小、吃喝/如厕对不准物件、睡猫穿窝、提起高度不足，以及切换动作略微缩小。

## 实现

- 猫砂盆由112×62扩大至190.4×105.4逻辑单位，绘制、脏污、点击、拖动边界和停留避让共用尺寸。默认位置略向左扩展，已有存档保留X（仅越界时夹取）。
- 吃喝路径终点使用盆中心左侧94单位，匹配当前朝右低头素材的嘴部。屏幕左缘给身体留位置；饭碗/水杯前唇覆盖进入盆口的下部嘴缘。当前素材本身的低头幅度仍保留。
- 左/右接近照料点后先播放停步，必要时真实转身，朝右站稳再进入22或26。转身时不扣库存，拖拽可立即打断；物件搬走后恢复寻路。
- 如厕及埋砂的支撑面抬高50单位，盆前壁在猫脚前绘制；入盆26渐升。
- 窝内支撑面统一为54单位，17渐升、19/20及21保持坐垫高度，18渐落。前沿遮挡与醒来过渡保持一致。世界坐标仍在底部水平线。
- 拎起时增加24单位的局部视觉高度，短时平滑跟随；放下34逐步落回地面。拖动仍只改变世界X。
- 52条视频增加同姿态端点比例校准，实测修正系数0.9900～1.0249。按固定根节点做三次平滑插值，不按每帧外框自动归一化，不叠画上一帧，不修改5883张PNG或原视频。动作查看器同步读取校准元数据。运动速度仍按原288尺寸计算。

## 验证与范围

217项模型、播放和几何回归通过；覆盖双向接近后的停步/真实转身、嘴部落点、左缘、放大猫砂盆边界、睡醒支撑面和悬空/落地。三种种子各一小时有效时间模拟仍完成吃喝，睡眠86.0%～89.9%、移动2.1%～3.5%。

WPF实际深色预览已检查吃饭、喝水、如厕、窝内睡眠及悬空。吃饭样本路径08→12→13→16→22→23，根节点X406、饭碗X500；如厕和悬空分别落在盆面与地面上方。截图及原始诊断保留在本地`artifacts/alignment/`，去除设备标识的摘要见[验证数据](qa/interaction-alignment/verification.json)。

Release自包含构建通过。此修正校准比例和物件接触，不把原视频内部姿态/形体变化当作全部重制通过，也不声称逐帧人工看完全部动画。元数据重建工具为`tools/calibrate_pose_scale.py`，同姿态端点高度数据见[校准数据](qa/interaction-alignment/scale-calibration.json)。
