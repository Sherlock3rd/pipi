# 吃喝遮挡与睡醒收缩复查

2026-09-19 用户反馈上一版仍收缩、吃喝穿模，补充集中在入睡/醒来与喝水开始瞬间。上一轮“已修复”结论不覆盖这些复现问题。

## 根因与修改

- 上次只匹配轮廓总高度。耳朵、尾巴和姿态会改变外框高度，按它缩放会给真实躯干引入错误比例。现在用同姿态的毛发特征匹配、RANSAC剔除不一致点，再拟合统一比例与位移；不旋转、拉伸、镜像或逐帧固定外框。52段元数据重新校准，原始PNG/视频未改。
- 蜷睡可以在任意呼吸阶段被打断，醒来首帧却总从固定阶段开始。新增121帧呼吸配准数据；立即唤醒时承接当前体型与位置，半秒平缓回到醒来片段，不延迟交互，不叠帧。
- **窝内醒来后、尚未走出猫窝时，旧18片段按时间把猫降到地面，身体被窝边挡住，产生假性收缩。** 改为始终由坐垫支撑完成醒来；开始横向走出后再按离窝距离逐渐落地。入睡前06/07/17等早期姿态也应用坐垫高度，不从窝底冒出。窝内拎起在坐垫之上增加提起高度。
- 原吃喝只重画当前碗的下方矩形，留下直线切口，邻近杯碗仍被猫身体盖住。当前碗沿弧形前沿拆为前/后两部分；其他杯碗完整画在前景。两部分互斥裁切，避免重复叠加透明边缘。实际可见的前景杯碗优先响应补给点击；碗后被猫遮住的开口仍可点猫。

## 验证

- 225项模型/播放/几何检查通过。新增全部121个呼吸阶段立即唤醒、同一时刻重复采样不累加校正、可随时拎起中断、半秒后不遗留缩放、进入与离开猫窝支撑高度等回归。
- 独立`tools/check_pose_seams.py`以实际对应特征点和显示变换检查130个接缝样本，最大躯干比例差0.265%，平均特征位置跳变均小于1.5逻辑单位。该量化检查衡量同姿态接缝，不等同于原视频内部所有姿态形变已重制。
- 5883张帧、5张道具及manifest引用检查通过。
- 隔离存档WPF连续采样覆盖吃饭/喝水进入、循环、抬头与退出，窝内进入睡眠、呼吸中点击唤醒和实际离窝。完整本地连续PNG在`artifacts/contact-v2/`，可公开路线摘要见[WPF路线](qa/contact-v2/wpf-routes.json)，数值审计见[接缝审计](qa/contact-v2/seams.json)。截图定时写盘会增加帧时，本次采样不作为性能基准。

## 重建

Python工具需Pillow、numpy、opencv-python-headless。先执行`tools/calibrate_pose_scale.py`生成元数据，再执行`tools/check_pose_seams.py`独立检查。运行时无OpenCV依赖；只读取manifest的校准值。
