# 屏边扶墙与工作台动作执行

2026-09-20。

## 扶墙为什么不触发
自主扶墙不是定时漫游：必须启用、未在本次进程中触发过、猫根节点距就近扶墙落点不超过40逻辑单位、附近无家具，且走到安静入睡决策。当前存档猫根约2481.5，屏宽3200，右扶墙落点约3156.7，相距675.2；右侧猫窝约2976.35也占用所需空位。因此当前状态不会自主触发。保留休息优先、不自动跨屏找墙的既有设计。

工作台屏边扶墙节点新增实时原因及左右侧可用性。双击节点选择就近侧，右侧面板可明确执行左侧或右侧。手动执行跳过概率、靠近范围和本次已触发限制，但仍检查素材、屏宽、家具安全空间；真实走到墙边再播放，禁止瞬移，不挪家具。

## 双击执行
单击选中节点编辑参数；双击动作立即作用于桌面陈皮。吃饭、喝水、如厕、回窝、移动、坐姿、五种睡姿、分组小动作、换姿与点击响应可执行。小动作参数旁另有精确动作按钮。组合/条件节点显示不可直接执行原因；开场设计仍等待独立跑步等素材，不能借调试绕过。

所选睡姿/小动作先到安全位置并完成真实姿态过渡；播放完恢复正常行为树。手动阶段暂缓自动照料抢占，点击、拖拽、逗猫棒仍能中断。实际吃喝扣库存，空盆或满猫砂会拒绝执行，不自动补货。参数草稿无需保存即可执行，但动作采用已生效参数。

逐帧实测发现旧扶墙停留5秒会切在循环中途（左56第23帧直接57第0帧）。现在自主与手动共同等到当前完整循环结束再落地；不改素材、体型、支撑点或播放速度。重复执行同一扶墙也等待新的循环边界。

## 设置入口
只对未被猫/其他物体覆盖的猫窝区域右键打开设置。猫、食水盆、猫砂盆、逗猫棒、空白处右键均无场景操作；持棒/拖动中也不响应右键。移除猫窝上方常驻“···”按钮、命中区域及托盘设置入口；从猫窝设置进入行为工作台。托盘仅保留召回、显示隐藏、退出恢复能力。
