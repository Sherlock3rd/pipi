# 清晰度、白底闪现与边缘复查

本轮直接修复用户提供视频的透明处理与运行渲染，不生成或重绘角色，不改变动作帧数、帧率、根节点、方向、逻辑尺寸与底部活动规则。

## 查明的问题

1. 旧提帧程序填充外轮廓时，连腿间的白色背景也填成了不透明主体。17转身、18转正、21睡醒和42坐起等动作出现随帧变化的白块。此前“轮廓近白像素为零”只覆盖轮廓3像素带，不能代表这些内部白底不存在。
2. 旧动作切换将上一帧完整保留在下面，新帧在100ms内渐入。两张姿态不完全相同的图叠加，形成双轮廓和模糊重影。
3. 高清帧的紧凑缓存没有透明采样边距；静态道具先解码至320像素，在高DPI或放大显示时会损失部分细节。

## 修复

- `refine_video_matte.py`识别连通的大块中性白底，恢复内部透明空隙及其边界毛色；细小眼睛高光保留。外轮廓按相对邻近毛色的亮度差清理灰白污染，补上旧220固定阈值的漏检。
- 量化后清除脱离主体的透明分量。实体内部非白色像素按字节比较，确认没有额外模糊或锐化；原片内部的毛发变化不作为透明背景删除。
- 新处理接入`rebuild_hd_video.py`，后续基础与照料提帧均沿用。`check_refined_matte.py --apply`处理已有帧，并将修改前帧备份到忽略上传的`artifacts/edge-focus/before`；重复执行从备份处理，避免叠加滤镜。
- 运行时每个时刻只画当前原动作帧，取消叠帧重影；保留既有动作衔接、位移和输入中断。裁切缓存增加2像素透明边距，道具解码提升至640像素。

## 验证边界

专项检查涵盖内部白底、边缘灰白污染、孤立亮点、眼睛高光和身体纹理保持；同时检查全量引用、512像素画布和透明边界。实际WPF在深色背景观察转身、坐起和移动切换。

自动阈值审计和有限时长动态抽查不能证明原视频所有纹理闪动完全消失；本轮修复的是已定位的白底、边缘采样和叠帧问题。最终统计在`docs/qa/edge-v3`和会话记录中。
