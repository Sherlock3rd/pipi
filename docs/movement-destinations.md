# 清醒移动与屏边扶墙

2026-09-20 用户明确：扶墙应与去其他地点处于同级，移动时按概率选择目的地。旧「仅临近屏边、入睡时、每次启动一次」逻辑撤销。

输入、家具避让、逗猫棒、缺货请求和实际照料优先。清醒空闲等待10～20秒后，本轮35%选择移动；未选中继续等待入睡，不每帧重抽。已入睡不因移动计时醒来，夜间/低能量/休息到期也优先睡眠。到达目的地或新一轮互动后重新计时。

移动池包含左部20%、中部50%、右部80%屏宽附近安全空位，以及屏边扶墙，初始权重各1。先过滤无空位、重复地点和距当前40单位内的普通目标，再归一化。扶墙不受当前距离限制，总权重由可用左右屏边均分，一侧被家具占用就排除该侧，两侧均堵则排除扶墙。目标在途中被家具占用时改去安全空位。目的地全部0或无可用位置时继续正常休息。

扶墙是「起身/转向/步行到屏边 → 扶墙进入 → 完整循环 → 落地 → 走到安全空位」。不截片、不改原图或体型、支撑和时长。照料可以抢占自主移动；工作台手动执行沿用手动保护。完成后仍可再次抽中扶墙。

工作台入口仍为猫窝右键设置。清醒自主移动节点可修改等待上下限、是否移动的概率、四项同级权重。移动节点双击直接执行同一个目的地选择器；扶墙节点可指定左右侧。已保存配置的其他值不改；旧v1 wall.chance接受读取但不再用于新树，避免老100%数值被误当作新权重。wall.enabled仍有效。

验证：541项模型/播放器检查通过。800个固定随机种子的四类选择次数为199/200/201/200，扶墙合计25%，没有因两侧而翻倍。单一正权重、两侧重复扶墙、阻挡筛选与途中重定位、全零、睡眠保护、照料抢占和旧配置读取均覆盖。WPF控件夹具验证保存回读、非法值和双击；59项参数。真实WPF自主路由各从远处进入左右墙，778帧，最大根步长左1.6602、右2.3224逻辑单位，入/循环/落地完整。逐相邻帧扫描证据见docs/qa/movement-choice/verification.json，原素材警报仍须复核，不把模型检查当作美术全部通过。
