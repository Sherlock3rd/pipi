# 回窝侧沿错误遮挡（2026-09-19）

用户再次提供回窝截图，后腿和尾根被左侧窝沿切断。上一轮虽然重描了轮廓，仍把整个高侧沿画到进窝猫的前面；“根节点进入坐垫”不能说明后腿、尾根已越过侧沿。因此此前左右回窝通过的结论不足，本次予以纠正。

改为明确的前后层：靠背与高侧沿属于猫后景，只有坐垫低前沿在猫前景。低前沿允许遮住贴垫的脚底，不再切入上腿、躯干与尾根。坐垫支撑高度、脚底轨迹、猫和窝尺寸、动画速度与原图不变。本轮没有制作新的跨越窝沿动画。

新增场景像素审计`--audit-nest-occlusion 输出目录`。使用实际WPF猫帧和窝前景图层，对左右各41个位置/步态样本统计被前景覆盖的猫像素；脚底上方12逻辑单位以上的身体不得被低前沿覆盖。保留旧高侧沿遮罩作为负对照，旧版必须检出至少100个错误覆盖像素，新版必须为0，否则退出码1。导出旧/新实际合成图供目视复核。它补充逐帧尺寸监测：单猫尺寸正确不代表家具遮挡正确。
