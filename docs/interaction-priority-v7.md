# 点击优先级、扶墙与埋砂收尾修正

2026-10-19，用户确认方案并要求合并代码冲突后提交打新包。

原问题是五部位入口无条件接管旧睡姿阶梯，并将宽泛躯干命中判成肚子。任何姿态都先转到B再播放143，连续点击还会积压后续动作。现按“当前行为/姿态→部位→兼容片段”处理，取消身体互动排队。

- 坐姿/站姿：不强制翻躺；站姿头与爪沿用同侧伸展/回头兼容反馈。肚子判定仅开放给B仰躺中央暴露区，其余躯干归背部。
- A侧躺、X舒展、B仰躺：沿原15秒固定窗口，首击轻反应、次击加强、三击起身。仅B第二次腹部点击以143替代73，两段不串播。快速点击合并到最高档。
- M掩面：单击85放爪回A结束。窝内睡眠：单击醒来结束。D趴卧：轻醒保持姿态。
- 吃喝、如厕、埋砂、跳出与落地期间：轻点不打断、不延后排队；拖拽沿原优先级。
- 扶墙：只把左右家具避让距离门槛乘0.1，普通休息避让及贴墙位置不变，详见movement-destinations.md。
- 埋砂完整收爪31后：每轮抽签一次，默认跳出/走出各50%。工作台“埋砂后跳出概率”可调0—100%。无安全落点或盆面已移走时走出；空中搬物后落地再避让；清理不重复整条如厕链。

Windows与Mac共享引擎、命中和设置参数；两个Scene提供真实显示姿态，避免以逻辑目标姿态代替当前轮廓。调试入口与普通点击使用同一规则。
