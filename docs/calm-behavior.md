# 休息优先行为调度

用户目标：陈皮大部分时间安静趴着睡觉，减少频繁活动。

## 调整

- 行为选择从每秒随机sit/idle改为持续安静待机，60秒无猫互动后就地睡眠。
- 基础待机保留01眨眼循环，取消02～05自动连播；原素材没有删改，仍可在素材查看器中查看。
- 到期休息只更新休息段，不再强制醒来漫游；新段20～60分钟，旧存档期限兼容。
- 点击睡猫立即醒来，取消30%随机换位；主动操作、真实照料仍可打断休息。
- 休息前保留空位检查，身处家具范围会先走到最近空位。窝内睡眠仍允许与窝重叠。
- 不修改素材、透明处理、步速、照料周期或五层库存。

## 验证

202项回归通过，包含40种子唤醒稳定性、休息期限后不漫游、空闲动作不每秒重选及原有照料/拖拽/家具避让。
