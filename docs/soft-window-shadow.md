# 轻柔轮廓阴影（2026-09-19）

用户提供浅窗口阴影参考，要求给陈皮及所有物品统一增加该效果。

陈皮、猫窝、食盆、水盆、猫砂盆（含砂堆）和逗猫棒完成原有遮挡合成后，以最终透明轮廓生成一层黑色柔影：透明度19%，模糊半径14逻辑单位，向下偏移3逻辑单位，随全局尺寸同步缩放。合成后加影避免窝沿/盆沿等分片重复投影产生黑缝；重叠物体按联合外轮廓投影，不模拟物体之间的光照。原有尺寸、脚底高度、位置、速度和前后遮挡保持不变。

使用保留的WPF DrawingVisual和DropShadowEffect，不改源PNG，不为动画逐帧额外生成位图。相伴计时、设置及拖入窝提示在独立无阴影层绘制。新增视觉子层不参与点击命中，继续由原物体范围处理输入，影子不扩大鼠标响应区。

预览参数 --preview-no-shadow 可生成关闭阴影的对照画面，仅在隔离预览有效。尺寸/接触/遮挡审计继续测量原实体像素，装饰阴影不计入猫体尺寸。
