## 批量接入

1. 每类一份独立帧序列，建议放在 `click-01/0001.png`、`click-01/0002.png` 等目录。PNG 透明背景，同动作各帧保持相同画布、猫脚底基准与朝向；当前播放器以 160×160 逻辑单位绘制，底边位于猫脚下方 18 单位，朝左会镜像。可提供更高分辨率等比例画布，避免动作间抖动。
2. 在 [manifest.json](manifest.json) 的 `animations` 对应 ID 中填写有序相对路径。只接受本素材目录内的 PNG。
3. 找到 `variants` 中同 ID 条目，设置 `enabled: true`。`fps` 为 1～30；`loop: true` 循环，`false` 播完停在最后一帧，直到行为结束。`draftIdea` 仅供制作记录，程序不显示。
4. `group` 为 `click` 或 `idle`，`baseAction` 选择承载该表现的现有行为：点击组 `pet/paw/roll`，待机组 `idle/sit/cute`。同一行为下可添加任意数量条目，无需改代码；建议按美术成品调整草案的分组归属。
5. 重启应用载入素材。开发源素材发布后才会复制到 `dist/Chenpi/assets/pets/bluecat`；直接修改分发包素材时应同步回源码，避免下次发布覆盖。

选取只在新动作开始时发生。同一基础行为下，已启用且完整载入的类型随机选取，有多个可选类型时避免连续重复；未启用、空帧、坏帧、错误配置自动排除。无可用类型时使用原基础动作素材或代码占位图，单个坏动画不影响其余动画。

此层只扩展视觉表现，不改变照料、移动、睡眠、点击唤醒、悬停蹭鼠标或引导优先级。当前点击行为长约 3 秒、普通待机片段约 1 秒、无互动卖萌约 5 秒；批量制作按对应时长匹配帧数，或使用短循环。后续若需要更长独立表演，再扩展时长规则。所有角色信息仍通过动作表达，不添加台词、照料数字或判定光圈。
