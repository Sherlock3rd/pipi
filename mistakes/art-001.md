# ART-001：生成工具参考图片数量限制

- 日期：2026-09-17。
- 分类：美术工具调用。
- 状态：已调整并完成生成。

首次向内置 image_gen 提交全部八张参考时，工具返回 `referenced_image_paths` 至多五张；该上限未在本轮公开参数说明中列出。此次请求在生成前被拒绝，不能记录成已完成图片。

重试选用身份和关键姿态互补的原图 02、04、05、07、08，在提示词中明确输入序号与原图编号的映射，生成成功。全部八张原图仍已阅读、本地归档并参与身份／行为规范，未因工具限制丢弃。

后续内置生成最多传入五张参考；先确定每张角色（身份、睡眠、侧躺、伸展、头部表情），保存输入映射。不要为了绕过数量限制切换收费 API 或丢失原始参考。
