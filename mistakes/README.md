## 执行前检查

- 用户提到“之前的 rule／specrule／基础环境”时，先定位已有规范与相关任务记录。
- 标准交付必须覆盖规则、总控会话、需求会话、错题、规范副本和术语表；单个 AGENTS.md 或安装依赖不能替代。
- 将用户确认、执行默认和待定建议分开，不能把功能方向选择当成框架选择。
- 复用通用机制，不复制其他项目业务、私有材料或推送授权。
- 错误发生后使用[模板](template.md)记录，补充可执行检查并同步会话。
- 初始布局使用最终窗口尺寸；检查实际窗口与导出预览，不能将应用渲染图当成桌面层级通过的证据。
- 显示模式验证包含完整往返与真实画面；换窗口保留同一实时模型，并清理旧帧、计时器和事件订阅。
- 手动指令与入窝不能只测调用瞬间；推进后续帧，覆盖请求／带路／照料到期及不同抓取位置，并验证自动行为最终恢复。
