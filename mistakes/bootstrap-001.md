# BOOTSTRAP-001：误把 specrule 环境当成桌宠运行环境

- 日期：2026-09-17。
- 分类：环境部署／范围理解。
- 状态：已纠正并验证。
- 关联需求：[规则环境部署](../session/requirements/rules-bootstrap.md)。

## 事实与影响

用户要求部署基础 rule 和环境、先调研成熟产品／skill。助手只检查空目录，未先定位历史规范，转而规划 Node／Electron 原型，并创建空应用目录、安装 hatch-pet。用户随后明确应基于之前的 specrule。

用户选择“轻量 2D”只确认功能方向，并未确认 Electron。纠正时尚未安装 Electron、创建应用代码或生成素材，影响是工作方向和时间偏离。

## 根因

没有优先复用已有规范，将“环境”解释为程序工具链；混淆工作流程环境与产品运行环境。此前 Interview 工作区已记录同类错误，本次初始未检索。

## 修复与验证

定位 DobeDemo 的 Rules Bootstrap Spec v1.0，完整复制并落实标准交付；停止产品脚手架工作，空目录暂保留，保留可复用的 skill 与调研。技术栈恢复待定，记录权限和设计边界。检查标准文件、链接与规范原文哈希。

## 同类防呆

收到复用环境请求时，先找源规范与同类错题；完成来源定位再选部署动作；不得用依赖安装或业务文档替代“规则—会话—错题—复用”。
