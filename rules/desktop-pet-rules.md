# 桌宠项目业务边界

## 用户已确认

- 本目录用于开发桌面宠物。
- 首版为轻量 2D，关注动画、拖拽和互动。
- 角色为小猫；通过一定的行为树自主移动，用户可喂饭、喂水，并把小猫拖回猫窝。
- 核心是桌面养猫与陪伴，不以键鼠计数／敲击反馈为主。原话和边界见[需求简述](../spec/desktop-cat-brief.md)。
- 详细需求已扩展至蓝猫素材替换、五物件、默认右下角猫窝和猫、桌面／悬浮设置、开机自启、系统作息与消耗、序列帧及日期皮肤，单一来源见[需求简述](../spec/desktop-cat-brief.md)。
- 电脑有效运行时间增加饥饿和口渴，即使桌宠完全退出；关机、睡眠／休眠暂停。猫实际吃喝时才扣库存并缓解需求；程序退出期间只累积需求，不补扣库存。游戏／视频／F11 全屏隐藏，普通最大化窗口仍可悬浮。入窝可点击立即唤醒，也可按作息／需求自然醒。
- 未照料只有催促，无死亡、离家、属性／关系损失或操作锁定等惩罚。
- 上轮遗漏项已由用户授权补全：释放入窝、催促冷却／合并／静音、托盘召回、默认布局恢复、缩放、状态反馈、存档恢复、动作过渡。详细默认规则见[照料与交互补充规范](../spec/desktop-cat-care-and-interaction.md)。
- 已授权实现，首版使用 WPF / .NET 10，具体已测范围见[原型验证](../docs/prototype-validation.md)。
- 不显示具体照料数值，以粮粒、水面与猫砂结块表现状态；默认布局紧凑，各物件可自由拖动并保存位置。
- 新增逗猫棒；慢节奏原地休息、5 分钟后原地睡、悬停蹭鼠标及交互圈规则见[休息与玩耍](../spec/desktop-cat-play-and-rest.md)，覆盖旧版频繁漫游。
- 猫不说任何文本台词，角色反馈全部动作化；删除所有气泡、文字催促、拖拽提示和行为原因面板。保留操作设置与陪伴时间。逗猫双方判定圈半径均为最初版本五倍。
- 判定圈不可视，仅在内部检测，不绘制光圈或范围覆盖层。
- 猫有外圈与贴身内圈：外圈立即追跑、内圈停下抓棒，按实时距离切换；禁止在大外圈里直接远距离抓空或先等待一段时间再追。

## 尚未决定

最新照料节奏与求助已由用户指定：独立喝水 10～30、吃饭 20～60、如厕 60～120 分钟；空粮／空水／满砂 5 分钟后中央下方请求，鼠标到猫身立即带往对应物品。细则及实现默认见[随机照料与带路](../spec/desktop-cat-care-schedules-and-guidance.md)，不再视为未定阈值。

- 首版自行实现 Windows 原型；最终支持平台范围及长期技术方案仍可评估。
- 蓝猫具体参考图／画风、帧数、行为树优先级、照料／冷却／长按数值、计时技术方案仍待确定；释放入窝及两种唤醒方式已明确，不重复二选一。
- “轻量”尚无内存、CPU、安装包体积的数值验收目标，不把任一框架标为已满足性能要求。

## 后续研发建议（尚非新增产品需求）

- 将[动画状态](../docs/beagle_glossary.md#动画状态)、资源与[桌面宿主](../docs/beagle_glossary.md#桌面宿主)分离。
- 对透明窗口、拖拽、点击穿透、多显示器／DPI、退出与恢复做实机验证。
- 素材记录来源和授权；代码许可不能自动覆盖角色图片、声音或模型。
- 开机自启开关是用户已确认需求，其默认值未指定；不得立即改动用户电脑自启设置。云端 AI、全局键盘记录、截图和自动更新仍未纳入需求。
- 有代码后验证相关行为与资源消耗，交付时明确哪些只通过静态检查、哪些经过实机运行。
